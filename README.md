# Traitweb

Paste a TFT team code, optionally add emblems, get a shareable trait-web image:
every pair of units sharing a trait is linked by a colored line with the trait
icon on it. Static site, no backend.

## Usage

Copy a team code from the in-game team planner and paste it in. Can also search
for champions manually.

Click a unit to attach emblems (max 3 each). The URL hash always holds the full
board, so the address bar is the share link. "Download PNG" exports the render
at 2x.
